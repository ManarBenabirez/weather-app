# Weather App

Application météo qui affiche la météo en temps réel d'une ville ou de la position actuelle.

Démo : https://manarbenabirez.github.io/weather-app/

## Fonctionnalités

- Recherche par nom de ville
- Météo de la position actuelle (géolocalisation)
- Température, description, humidité et vitesse du vent

## Technologies

- HTML
- CSS
- JavaScript
- API OpenWeatherMap

## Utilisation

Ouvrir le fichier `index.html` dans un navigateur.
